# Product Images

Drop product images here named exactly after the **Product Code** from the catalog.

Examples:
- `KB25_WE.jpg`
- `EZ9F53220.png`
- `DEYE 8KW.jpg`

Supported: `.jpg`, `.jpeg`, `.png`, `.webp`

The product page automatically picks them up — refresh the preview after uploading.
Products with no matching image show a "Coming Soon" placeholder.
